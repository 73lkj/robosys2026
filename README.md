# wheelコマンド
![test](https://github.com/73lkj/robosys2026/actions/workflows/test.yml/badge.svg)

タイヤの直径と回転数から走行距離を計算するコマンド。`-r`で、距離から回転数も計算できる。
また、`-c`を付けると左右2輪のロボットが円を1周するときに、左右のタイヤが進む距離と必要な回転数を計算できる。

長さはすべてmm、結果は小数第2位まで出る。

## インストール手順
```
$ git clone https://github.com/73lkj/robosys2026.git
$ cd robosys2026
```

## 使い方
### 距離
```
$ seq 3 | ./wheel 65
204.20
408.41
612.61
```
- 標準入力に回転数を入れると、直径を引数として距離を出力する。

### 回転数
```
$ echo 1000 | ./wheel -r 65
4.90
```
- 標準入力に距離を入れると、直径を引数として回転数を出力する。

### 円を描くための計算
```
$ echo 100 | ./wheel -c 65 150
157.08 1099.56 0.77 5.38
```
- 標準入力にロボットの中心から測った半径を入れると、タイヤの直径とトレッド幅を引数として、左タイヤの走行距離・右タイヤの走行距離・左タイヤの回転数・右タイヤの回転数を出力する。
- 出力は左回りの場合の値で、半径がトレッド幅の半分より小さい場合は、左タイヤが逆回転するため、左タイヤの走行距離と回転数が負の値になる。

### エラー
- 直径またはトレッド幅が指定されていない場合、0以下の場合、または入力・引数が数字でない場合は、エラーメッセージを出力して終了ステータス1で終了する。
