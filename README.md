# wheelコマンド
![test](https://github.com/73lkj/robosys2026/actions/workflows/test.yml/badge.svg)

タイヤの直径と回転数から、ロボットが進む距離を計算する。また、`-r`で逆の計算も可能である。引数は直径(mm)、標準入力は回転数(`-r` のときは距離(mm))とする。結果は小数第2位まで出る。

## インストール手順
```
$ git clone https://github.com/73lkj/robosys2026.git
$ cd robosys2026
```

## 使い方
### 距離
```
$ seq 3 | ./wheel 65
204.20
408.41
612.61
```
- 標準入力に回転数を入れると、直径を引数として距離を出力する。

### 回転数
```
$ echo 1000 | ./wheel -r 65
4.90
```
- 標準入力に距離を入れると、直径を引数として回転数を出力する。

### エラー
- 直径がない、直径が0以下、入力が数字でない場合は、エラーメッセージを出して終了ステータス1で終わる。
